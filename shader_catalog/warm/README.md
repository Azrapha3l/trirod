# Shared Vulkan warm recipes

This directory contains curated runtime-discovered Maxwell shader code records and pipeline recipes. The portable
recipe file uses schema 2 and wildcard GPU IDs. Each install validates the recorded Vulkan formats, retranslates the
guest shaders with its current Trirod translator, and builds supported pipelines with its own Vulkan driver.

The local `cache/vk_pipelines.bin` is an opaque driver cache and does not belong here. Runtime `cache/glsl` files are
diagnostic dumps. Runtime `cache/spirv` files are regenerated by ShaderPrep from these code records and the game
shader catalog, so those cache directories are not copied into the repository or release package.

After playing a development build, merge its learned recipes into this catalog from the repository root:

```powershell
python tools\export_shader_warm.py "[local path omitted]"
```

The exporter reads only `cache\warm\recipes.bin` and the code files those recipes reference. It validates the record
checksums and shader content hashes, merges with the existing catalog, and writes the result here. Review the new
file count and repository size before committing the updated catalog.
